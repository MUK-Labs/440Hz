Install it in three steps

Open this page on your Android phone, then follow these steps.

  1. Download the APK

    Tap Download test APK above. Look in Files → Downloads if you cannot find it. A GitHub “Source code” ZIP is not the app.

  2. Tap it to install

    Open the APK and tap Install. If Android blocks it, follow the prompt to allow installs from this source for the browser or Files app you are using. Return to the file and tap Install again.

  3. Open 440

    Tap Open when installation finishes, or find 440 in your app list. Turn up media volume and tap the large 440 button to hear A.

Phone menus differ. If needed, search Android Settings for Install unknown apps and allow the specific app opening the APK. Only install a file you trust. You can switch that permission off again afterwards; keep Play Protect enabled. Google's APK installation help

Start practising

440 never plays by itself when you open the app or receive a reminder. You choose when to compare your pitch with the reference.

  1. Switch on Random reminders and allow notifications. In Reminder settings, choose days, active hours and how often you want a nudge; tap Save.
  2. Tap Test reminder. When the phone vibrates, imagine or sing A. Tap the notification to open 440, then press the large 440 button to hear it.
  3. Optional: enable Shake after reminders. Test again, wait for the vibration to finish, then give the phone two brisk shakes within 60 seconds. A plays once, even with the screen locked on supported phones.
  4. Optional: tap Add home-screen widget for one-tap playback.

Something not working?

Try the matching check below. Your phone's menu names may differ a little.

I cannot hear A

Turn up media volume, then tap the large 440 button. Check whether the sound is going to headphones or a Bluetooth speaker.

No reminder or vibration arrives

Check Random reminders, your chosen hours/days and whether the run has ended. Tap Test reminder. In 440's Notification settings, allow notifications and vibration for Pitch reminders. Also check Do Not Disturb. Battery saving may delay scheduled reminders.

Shaking does nothing

Turn on both Random reminders and Shake after reminders. Tap Test reminder, wait until the vibration ends, then shake twice briskly within 60 seconds. If needed, try Reminder settings → Shake sensitivity. Reopen 440 after a reboot, update or force-stop. Do Not Disturb prevents shake playback. Phones without an accelerometer cannot use this mode.

The APK will not install or update

Check that your phone runs Android 8.0 or newer and that the file ends in .apk. If an older copy of 440 is installed, ask the maintainer for an update signed with the same key. Do not uninstall the old copy before checking: uninstalling erases its settings. If Android flags the file as unsafe, do not bypass that warning; ask for a verified copy.
